# VanillaCore — серверный плагин

Ядро игровой части: авторизация, наказания, админка, репорты, экономика.
Paper 26.2, Java 25.

Плагин не ходит в базу — только в HTTPS API сайта (`https://vanillacraft.click`) с общим токеном
(`api.token` = `MC_SERVER_TOKEN` сайта). Вся логика денег и наказаний живёт на
сайте, здесь остаётся игровая механика.

## Сборка

```
cd plugin
JAVA_HOME=/path/to/jdk-25 mvn package
```

Результат: `target/VanillaCore-1.0.0.jar` → в `plugins/` сервера.
paper-api 26.2 собран под Java 25, поэтому JDK 21 не подойдёт.

## Авторизация

`online-mode=false`, аккаунты живут на сайте.

1. Игрок заходит — он в adventure, заморожен, ослеплён, команды кроме
   `/login` и `/2fa` заблокированы. На ввод даётся минута.
2. `/login <пароль>` → API. Ответ решает: пустить, спросить 2FA, кикнуть.
3. Вход с нового IP → `/2fa <код>`, код берётся в личном кабинете.
4. Три неверных пароля — кик, всё пишется в журнал входов.

## Команды

| Команда | Уровень | Что делает |
|---|---|---|
| `/login`, `/2fa` | все | Вход |
| `/balance` | все | Баланс VC и уровень аккаунта |
| `/promo <код>` | все | Промокод медиапартнёра (нужен 3 уровень) |
| `/bonus <код>` | все | Бонус-код |
| `/report <текст>` | все | Жалоба администрации |
| `/spec` | 1+ | Режим наблюдателя |
| `/esp` | 2+ | Подсветка игроков ниже своего уровня |
| `/ajail <ник> <причина> <минуты>` | 2+ | Деморган (helper — до 60 минут) |
| `/asms <ник> <текст>` | 2+ | Личное сообщение от администрации |
| `/tp`, `/tphere` | 2+ | Телепорт |
| `/reports` | 2+ | Меню репортов |
| `/warn <ник> <причина>` | 3+ | Варн на 7 дней |
| `/ban <ник> <причина> <дни>` | 3+ | Бан |
| `/check <ник> <ссылка>` | 3+ | Проверка на читы; `/check <ник> pass\|fail` — завершить |
| `/news <текст>` | 5 | Глобальная новость |

Уровень берётся из профиля на сайте, а не из прав Bukkit: выдал в панели —
через переподключение игрок получил доступ.

## Деморган

Время идёт **1 к 10**: срок 60 минут отбывается за 6 минут реального времени,
и только пока игрок онлайн. Добыча породы списывает по 20 секунд срока за блок
(настраивается). Дропа и опыта с породы нет — это отработка, а не фарм.

Инвентарь забирается и возвращается после отсидки; состояние раз в 30 секунд
уходит на сайт, так что срок переживает рестарт и виден в админ-панели.

Если инвентарь не удалось сохранить, вещи не отбираются. Если не удалось
вернуть — Base64 пишется в лог строкой `INVENTORY-DUMP`.

## ESP

- **Медиа (1 уровень)** светятся красным для всех — зрители должны видеть, что
  человек снимает.
- **Админам 2+** доступна команда `/esp`: свечение целей отправляется
  персонально через `sendPotionEffectChange`, поэтому обычные игроки его не
  видят. Подсвечиваются только те, кто **ниже** по уровню — старших ESP не палит.

Своего лаунчера нет, поэтому это единственный честный способ дать ESP без
клиентских модов.

## Проверка на читы

`/check <ник> <ссылка>`: игрок обездвижен, на экране титры, в чате кликабельная
ссылка. Все команды кроме `/check` и `/report` ему заблокированы. Выход во время
проверки — уведомление всем админам и запись в журнал.

## Репорты

`/report <текст>` создаёт жалобу и уведомляет всех админов от 2 уровня.
`/reports` открывает меню. Захват репорта делает сайт: первый успевший забирает,
остальные получают «уже взят» — даже если нажали одновременно.

## Bedrock-клиенты

На сервере стоят Geyser и Floodgate: игроки с Bedrock-версии заходят на тот же
адрес и порт, что и Java-игроки — Java идёт по TCP, Bedrock по UDP.

| Порт | Протокол | Кому |
|---|---|---|
| 25590 | TCP | Java |
| 25590 | UDP | Bedrock (Geyser) |
| 25996 | UDP | Simple Voice Chat |

Floodgate добавляет никам Bedrock-игроков префикс `.`, чтобы они не
сталкивались с Java-никами. Сайту про этот префикс знать незачем: перед любым
обращением к API он снимается (`Accounts.name`), поэтому аккаунт **один** — с
какого бы клиента человек ни зашёл. Пробелы в геймертегах Floodgate заменяет на
`_`, так что ник проходит проверку сайта.

Админские команды понимают обе формы имени: и `Nick`, и `.Nick` найдут одного и
того же игрока.

Префикс задаётся в двух местах и должен совпадать: `auth.bedrock-prefix` в
конфиге VanillaCore и `username-prefix` в конфиге Floodgate.

## Ограничения без своего лаунчера

- **HWID-бана нет.** Идентификация только по аккаунту и IP.
- **Полёт по F5 невозможен** — вместо него команда `/spec`.
- **Войс-чат** ставится отдельно: серверный плагин Simple Voice Chat, игроки
  ставят клиентский мод сами.
