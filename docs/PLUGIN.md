# Demorgan

Плагин для Paper: **исправительные работы вместо бана**. Нарушитель не теряет
прогресс и не уходит с сервера — он отрабатывает срок в изолированной зоне.
Механика взята с «деморгана» Majestic RP, но без ролевой обвязки: это чисто
дисциплинарный инструмент для ванильного сервера без приватов.

## Как это работает

1. Админ выдаёт срок: `/demorgan Steve 60 гриферство спавна`.
2. Инвентарь игрока сохраняется, точка задержания запоминается, игрок
   переносится в отдельный мир `demorgan` и получает кирку.
3. Срок тикает **только пока игрок онлайн** — отсидеться в оффлайне нельзя.
4. Добыча породы ускоряет освобождение: каждый блок списывает
   `sentence.seconds-per-block` секунд. Дропа и опыта с породы нет — это
   отработка, а не фарм.
5. По истечении срока инвентарь возвращается, игрок телепортируется на точку
   задержания.

Выйти нельзя: заблокированы команды (кроме белого списка), выброс предметов,
чужие инвентари, телепорты, порталы, взаимодействие с блоками. Смерть,
реконнект и выход за границы зоны возвращают в неё же.

## Сборка

```
mvn package
```

Готовый плагин: `target/Demorgan-1.0.0.jar` → в папку `plugins/` сервера.
Требуется Paper 26.2 и Java 25.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/demorgan <ник> <минуты\|auto> <причина>` | `demorgan.admin` | Выдать срок |
| `/demorgan check <ник>` | `demorgan.check` | Остаток срока и число нарушений |
| `/demorgan list` | `demorgan.check` | Кто сейчас сидит |
| `/demorgan reload` | `demorgan.admin` | Перечитать config.yml |
| `/unmorgan <ник>` | `demorgan.admin` | Освободить досрочно |

`auto` берёт срок из прогрессивной шкалы `sentence.escalation` по числу прошлых
нарушений игрока (по умолчанию 30 мин → 2 ч → 6 ч).

Права: `demorgan.exempt` — игрока нельзя посадить; `demorgan.seechat` — видеть
чат заключённых (он изолирован от общего).

## Конфигурация

Всё в `config.yml`: геометрия арены, материал породы, время регенерации блоков,
выдаваемый инструмент, курс «блок → секунды», шкала сроков, белый список команд,
вебхук Discord для лога выдач.

Мир `demorgan` и арена создаются автоматически при первом запуске
(`zone.auto-create`). Арена перестраивается при каждом старте, так что сломать
её нельзя. Геометрия применяется только после рестарта, `reload` её не трогает.

## Логирование

Каждая выдача и снятие срока уходят в Discord-вебхук
(`discord.webhook-url`). Без внешнего лога админку невозможно контролировать —
настоятельно рекомендуется включить.

## Данные

Состояние в `plugins/Demorgan/data.yml`: активные сроки (включая инвентарь в
Base64) и счётчик нарушений по каждому UUID. Сохраняется раз в минуту, при
выходе игрока и при остановке сервера.

Если инвентарь не удалось сохранить, плагин не отбирает вещи — игрок уходит в
зону со своим инвентарём. Если не удалось вернуть — Base64 пишется в лог
сервера строкой `INVENTORY-DUMP`, чтобы вещи можно было восстановить вручную.

## Деплой на хостинг с панелью Calagopus (Bisquit.Host)

API панели Pterodactyl-совместимый, тот же домен что и веб-интерфейс.
Ключ создаётся в аккаунте панели, передаётся как `Authorization: Bearer <key>`.

```
PANEL=https://mgr.bisquit.host/api/client/servers/<server-id>

# Paper вместо ванильного jar (панель скачает сама)
curl -X POST -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"url":"<paper-jar-url>","directory":"/","filename":"paper.jar"}' "$PANEL/files/pull"

# Переименование (бэкап старого jar)
curl -X PUT -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"root":"/","files":[{"from":"server.jar","to":"vanilla.jar.bak"}]}' "$PANEL/files/rename"

# Загрузка плагина (files/write принимает бинарь и создаёт папку сам)
curl -X POST -H "Authorization: Bearer $KEY" -H 'Content-Type: application/octet-stream' \
  --data-binary @target/Demorgan-1.0.0.jar \
  "$PANEL/files/write?file=%2Fplugins%2FDemorgan-1.0.0.jar"

# Состояние и запуск
curl -H "Authorization: Bearer $KEY" "$PANEL/resources"
curl -X POST -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"signal":"start"}' "$PANEL/power"
```

Эндпоинт `files/upload` отдаёт signed URL на демон (порт 8080) — снаружи он может
быть недоступен, тогда используйте `files/write`, он работает через саму панель.

### Версии

Плагин собирается против paper-api 26.2. Сервер должен работать на Java 25 —
Minecraft 26.1+ более ранние не принимает.
